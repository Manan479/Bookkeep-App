# Dashboard customization, responsive layouts and accent readability

Changes since GitHub `main` at `0fd2da7` (the previous synchronized commit).

## Dashboard and appearance

- Added Customize with visibility and ordering controls for 11 sections, desktop drag handles, mobile/keyboard ordering arrows, Cancel, Save layout and Restore defaults. Layout preferences are stored on this device, outside business backup/cloud records.
- Reworked dashboard metric rows, account balances and summary sections to use the available width when widgets are hidden or reordered. Removed excess metric height.
- Fixed stock alerts retaining a two-column inner grid when only one alert exists. Alerts now fill their widget and align with the adjacent cards.
- Summary cards use neutral surfaces with an accent border, preserving clear text across accents. Filled controls and swatch checks choose black/white by luminance contrast; accent text on neutral surfaces uses an adjusted tone.
- Redesigned and centered sign-in, matched user selector and PIN field styling, added inline feedback, and updated desktop scrollbars to follow the theme.

## Layout consistency and record actions

- Bounded desktop editors and text-led details to a consistent reading width. Aligned their action footers, standalone upload/actions and search fields with the content column.
- Standardized list filter/control sizes and ordering, moved desktop create actions into headers, stabilized Payments columns and preserved readable table widths on narrow desktop workspaces through horizontal scrolling.
- Enabled Parties and Inventory selection with filtered bulk exports. Added the selected-document fallback needed by invoice batch export.
- Consolidated quotation actions and removed duplicate Edit. Mobile detail actions use a separate row; long detail values wrap without touching labels.
- Added compact Settings/Templates sections and section navigation, full template preview with fit/actual-size controls, and desktop report exports in the header.
- Unified mobile and desktop SVG icons, enlarged mobile touch targets and isolated Latin dates from RTL text ordering.

## Mobile behavior

- Added invoice discard confirmation, contained sheets within their viewport, improved wide report scrolling and mobile preview zoom.
- Corrected selection indicator placement and preserved the text slot when selection starts. Selection is cleared on navigation, and long-press handling avoids side gestures.

## Verification and delivery

- Broad Edge review: 71 screen states at 1440/1024/390px (213 runs), with no detected page overflow or runtime errors; six existing interaction checks passed. This is a representative review, not exhaustive proof for every record and device.
- Focused layout checks passed at 1440/900/390/320px for detail headers, settings navigation, preview controls, list actions, RTL dates and report exports.
- Dashboard regression checks passed one/two-alert geometry at 1440/1024/390/320px; rendered summary/filter contrast reached at least 4.5:1 for 16 accents in light/dark modes at 1440/390px. Cancel, visibility/order saving, reload persistence and defaults passed. Screenshots were inspected on desktop and mobile sizes.
- Reproduction tools: `tools/layout-regression.cjs` and `tools/dashboard-review.cjs`. Generated local evidence is under ignored `dist/layout-review/` and `dist/dashboard-review/`.
- Standalone `dist/bookkeep.html` regenerated. An earlier desktop rebuild is recorded in this history; the current fixes have not been packaged for desktop or Android. Native Android behavior, physical printing, installed Electron scaling and live cloud behavior still require separate verification.
- Existing accounting calculations and permission rules were preserved. Layout customization does not change report/export figures or grant access to features.
